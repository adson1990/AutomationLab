
# AutomationLab

## Objetivo
Projeto pessoal para demonstrar automação de cadastros web a partir de planilhas, com validação, relatório de execução e retomada de processos interrompidos.

## Tecnologias
- Java 17
- Spring Boot 4.x
- Maven
- Spring MVC e Thymeleaf
- Spring Security
- Bean Validation
- H2 Database
- Selenium WebDriver (etapa futura)

## Funcionalidades planejadas
1. Login e controle de acesso.
2. Cadastro de alunos.
3. Listagem, pesquisa e paginação.
4. Importação de CSV.
5. Automação de cadastros via Selenium.
6. Histórico persistente de execuções.
7. Retomada de registros pendentes.
8. Relatório de sucessos, falhas e tentativas.

## Regras de desenvolvimento
- Trabalhar em etapas pequenas.
- Explicar decisões técnicas em linguagem clara.
- Inspecionar os arquivos existentes antes de modificá-los.
- Não reescrever arquivos inteiros sem necessidade.
- Não inventar regras de negócio; perguntar quando houver dúvidas.
- Executar os testes pertinentes e informar os resultados reais.
- Não afirmar que um teste foi executado se não foi.
- Preservar as alterações existentes.

## Segurança
- Utilizar somente dados fictícios.
- Não incluir credenciais ou segredos no código.
- Não reutilizar código proprietário ou dados internos de empregadores.
- Manter o projeto independente dos ambientes profissionais.

## Forma de ensino
O desenvolvedor quer aprender a construir a solução, não apenas receber código pronto.
Explicar o papel de cada componente e como executar e validar as mudanças.
